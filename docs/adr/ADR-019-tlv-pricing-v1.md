## 1. ADR本文（決定）

### 1.1 決定サマリ

TASFUL TLV の正式な料金・還元の **思想と骨格** を次のとおり固定する。

| 柱 | 決定 |
| --- | --- |
| 基本思想 | **利益最大化ではない。長期継続運営を優先する。** |
| 差別化 | コイン価格競争ではない。**出来高制 · Creator Economy · Options/Benefits（AD-040）** で差別化する。 |
| コイン | **1 Coin = 1 円**（業界標準の分かりやすさを採用） |
| 運営予算 | 実コスト吸収のための運営予算思想を維持（「利益枠」と誤解しない） |
| **投げ銭分配（SSOT = AD-040）** | 月間投げ銭売上ティア（下表）。**条件達成型 Rank で分配率を決めない** |
| Rank / Score | 露出 · 特典 · 健全性等の **別軸**（分配率決定条件ではない） |
| AI 社員 | 売上・コスト・利益・分配・Benefit を監査し **改善案のみ提出**。自動変更禁止。最終決定は運営者。 |

#### 投げ銭分配（現行 SSOT · AD-040）

| 月間 Eligible Net の部分 | Creator限界率 | TASFUL限界率 |
| --- | ---: | ---: |
| **0〜500万円部分** | **80%** | **20%** |
| **500万円超〜1,000万円部分** | **90%** | **10%** |
| **1,000万円超〜3,000万円部分** | **95%** | **5%** |
| **3,000万円超部分** | **99%** | **1%** |

本 ADR（v1）は思想と骨格の確定までとする。  
コイン販売・ギフト・出金・ランク条件・サブスク・法務・不正対策の詳細は **Phase 2（後継 ADR）へ持ち越す。**

### 1.2 基本思想

1. **長期継続運営を優先する** — 短期の取分最大化や最安コイン競争を目的にしない。  
2. **差別化は還元・Economy・Options** — 「生み出した価値がどう公正に戻るか」と AD-040 Option/Benefit。  
3. **投げ銭分配は売上ティア** — AD-040。Rank/Score 条件達成で分配率を上げる旧モデルは **SUPERSEDED**。  
4. **運営予算はインフラと継続のため** — 「利益枠」と誤解しない。  
5. **人間が最終決定する** — AI は監査と提案まで。レート・条件・価格の自動変更は禁止する。

### 1.3 コイン

| 項目 | 決定 |
| --- | --- |
| 換算 | **1 Coin = 1 円** |
| 方針 | 業界標準の分かりやすさを採用する |
| 小数 | コインは整数（既存 `docs/PRICING.md` の整数原則と整合） |

> Web / App の販売パック価格差・IAP 手数料吸収・ボーナス付与などは **Phase 2** で定める。本 v1 では「内部・表示の基本単位が 1 Coin = 1 円」を固定する。

### 1.4 運営予算思想

| 項目 | 決定 |
| --- | --- |
| 性質 | 運営取り分は **利益枠ではなく**、CDN / API / Cloudflare / サーバー / ストレージ / 保守等の継続費用を賄う **運営予算** として扱う |
| Actual Profit | AD-040 の Actual TLV Profit 把握と整合 |

> 決済手数料の控除順序、Net 定義、税の扱いは既存 AD-014 / `FINANCIAL_MODEL.md` / `TLV_PAYMENT_ENGINE.md` と整合させ、**Phase 2 で計算式を確定**する。

### 1.5 投げ銭分配と Rank/Score の分離

| 項目 | 決定 |
| --- | --- |
| **TLV Revenue Share** | **AD-040 `TLV_PROGRESSIVE_V1`のみ**（§1.1 表） |
| Rank / Score | 削除しない。露出・特典・健全運営・Pool 等の **別軸** |
| 禁止 | Rank/Scoreまたは到達Bracketの単一率をEligible Net全額へ適用すること |

## 2. 採用理由

1. **長期継続** — Live は CDN・Realtime・ストレージコストが重い。運営予算と Actual Profit（AD-040）を把握して継続する。  
2. **差別化の明確化** — コイン単価競争ではなく、公正な投げ銭分配（売上ティア）+ Options/Benefits。  
3. **AD-040 整合** — 投げ銭分配は月間売上ティア。Rank/Score は別軸。  
4. **1 Coin = 1 円** — 説明コストを下げ、視聴者・配信者・運営の認識を揃える。  
5. **95% の希少性** — 月間投げ銭 **≥1000万** 帯のみ（AD-040）。一律高還元を防ぐ。  
6. **AI は監査まで** — 一人運営を支えつつ、金銭条件の最終権限を人間に残し、事故と信頼毀損を防ぐ。

## 4. 運営思想

```text
価値の流れ（概念 · AD-040）

視聴者支出（コイン等）
    ↓
決済・原価控除（Phase 2 で式確定）
    ↓
投げ銭分配（AD-040 月間売上ティア）
  <500万: Creator 80% / TASFUL 20%
  ≥500万: 90% / 10%
  ≥1000万: 95% / 5%
    ↓
TASFUL 側: Streaming/API/Infra/Payment/Option 原価 → Actual TLV Profit
Rank/Score: 別軸（露出・特典・健全性 · 分配率決定ではない）
```

- 運営は「取れるだけ取る」のではなく、**配信が明日も回る予算**と Actual Profit を把握する（AD-040）。  
- 配信者の分配額は **月間Eligible Netの累進Bracket合計** で決まる（条件達成Rank・単一率ではない）。  
- コイン価格で勝負せず、**公正な分配 + Options/Benefits** で選ばれる。

## 5. AI 監査思想

| 原則 | 内容 |
| --- | --- |
| 役割 | 毎日の数字を監視し、異常と改善余地を言語化する |
| 権限 | **提案のみ**。レート変更・出金・BAN・価格変更の自動実行はしない |
| 対象 | 売上 · コスト · 利益 · 還元率 ·（推奨）運営予算 20% の健全性 |
| エスカレーション | 閾値超えや不正疑い → 運営者へ報告 |
| 最終決定 | 運営者のみ |
| 本 ADR | 監査の **方針**のみ確定。ダッシュボード実装・自動ジョブは別タスク |

AI 秘書（AD-010）や TASFUL AI（AD-018）とは役割が異なる。  
ここでの「AI 社員」は **TLV 経済の日次監査係** であり、利用者向け LLM 商品ではない。
