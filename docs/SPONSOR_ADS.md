## 1. 目的

TASFUL **全体で統一したスポンサー広告システム**を導入し、事業者・企業が露出を増やせる広告商品を提供する。

| 守るもの | 内容 |
| --- | --- |
| **公平性** | 通常検索・通常案件・通常掲載の順位・露出ロジックは **広告課金で歪めない** |
| **透明性** | スポンサー枠は **スポンサーであることを明記**する |
| **分離** | 広告枠は **通常一覧と分離表示**する（同一リストへの混在ソート禁止） |
| **検索品質** | マッチング品質・信頼シグナルを優先し、金払い順の organic を作らない |

本ドキュメントは **TASFUL 共通スポンサー広告システム**の正本とする。  
各サービス固有の課金（Contact Reveal · BD 掲載サブスク · Builder AI 等）とは **商品レーンを分離**する。

## 2. 共通ルール（全サービス必須）

| # | ルール |
| --- | --- |
| 1 | **スポンサーであることを明記**（ラベル省略禁止） |
| 2 | **通常検索順位には影響させない**（organic スコアへの課金加点禁止） |
| 3 | **広告枠と通常一覧は分離**（別ブロック表示） |
| 4 | **広告枠は少数**（例: **3〜5 件**程度 · 面ごとに上限を実装時確定） |
| 5 | **検索品質・公平性を維持**する |

### レイアウト原則（共通）

```text
┌─────────────────────────────┐
│ スポンサー枠（ラベル必須）      │
│ （少数 · 例 3〜5 件）          │
│  A · B · C                    │
└─────────────────────────────┘
──────────── 区切り ────────────
┌─────────────────────────────┐
│ 通常一覧（organic）            │  ← 広告の影響を受けない
│  …                            │
└─────────────────────────────┘
```

## 5. 共通システム構想（設計メモのみ）

実装しないが、将来の統一を見据えた論理構成:

```text
共通スポンサー広告システム（論理）
├── 共通ルールエンジン（明記 · 分離 · organic 非干渉 · 枠上限）
├── 共通商品カタログ（7/14/30 日 · 月額 · 地域/カテゴリ将来）
├── 面アダプタ
│   ├── Platform（スポンサー案件）
│   ├── Builder（スポンサー案件 · スポンサー業者）
│   ├── Business Directory（スポンサー掲載）
│   └── Future（TLV · AI おすすめ枠 · ホームバナー · カテゴリ）
└── 計測・審査・管理（将来）
```

| 原則 | 内容 |
| --- | --- |
| **ルール共通** | ラベル · 分離 · 枠数 · organic 非干渉は全面同一 |
| **面アダプタ** | 表示コンポーネント・対象エンティティ（案件 / 業者 / 掲載）は面ごとに接続 |
| **課金レーン独立** | Contact Reveal · BD 掲載サブスク · Builder AI · TLV Wallet 等と **混同しない** |

## 8. 受け入れの考え方（将来実装時）

- スポンサー枠と通常一覧が **視覚的・論理的に分離**されている
- スポンサー OFF / 枠ゼロでも通常一覧の順位が変わらない
- ラベルが欠落したスポンサー表示は **リリース不可**
- 枠数が上限（例: 5）を超えない
- Platform / Builder / BD で **共通ルールが同一**である
