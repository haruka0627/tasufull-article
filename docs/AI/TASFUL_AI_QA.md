# TASFUL AI — サイト内 QA レスポンス設計

**最終更新:** 2026-06-30  
**ステータス:** **設計確定（実装未着手）**  
**決定:** [DECISIONS.md](../DECISIONS.md) **AD-015**

---

## 概要

サイト内 AI（TASFUL AI Workspace · Site Assistant 等）で **QA に該当する質問** が入力された場合、該当 **QA 記事** を検索し、**QA 記事コンポーネント** を AI 回答欄にそのまま表示する。

| 項目 | 内容 |
| --- | --- |
| **Single Source of Truth** | **QA 記事コンポーネント**（1 種類 · データ差し替えのみ） |
| **表示先** | QA 詳細ページ（`/help/*`）**と** サイト内 AI 回答欄 — **同一コンポーネント** |
| **AI の役割** | 該当 QA 記事を特定する · **別回答文・別 UI は生成しない** |
| **禁止** | AI 専用回答 UI · QA ページと AI 用の二重管理 · QA ごとの独自レイアウト |

---

## 基本方針

1. **QA データを作る**
2. **QA 記事コンポーネント** で表示する
3. **QA 詳細ページ** はそのコンポーネントを表示する
4. **サイト内 AI** で QA ヒット時も **同じコンポーネント** を表示する

**検索カード UI**（`ai-search-result-card` 系）とは **完全に分離** する。QA ブロックと検索カードを同一カード内に混在させない。

---

## 表示例

### ユーザー入力

```text
会員登録はどうやるの？
```

### ヒットする QA

`01. 会員登録方法`

### AI 回答欄の表示

QA 詳細ページ（`/help/signup` 等）で使う **「01. 会員登録方法」** と **同一レイアウト** を、そのままサイト内 AI の回答として表示する。

```text
🤖 TASFUL AI
ご質問に関連する案内が見つかりました。

01. 会員登録方法

💬 質問
会員登録はどうやるの？

［AI 回答ボックス］
（intro · 手順 · 注意 · CTA · 関連ページ — データ差し替え）

［役に立ちましたか？］
```

ページ専用ブロック（更新日 · 前後 QA ナビ等）は **詳細ページ側のラッパー** に載せ、コンポーネント本体は共有する。

---

## QA 記事コンポーネント（共通 · 1 種類）

**QA ごとの独自レイアウトは作らない。** 中身だけ QA データで差し替える。

### コンポーネントに含めるブロック

| ブロック | 内容 |
| --- | --- |
| 共通ヘッダー | 🤖 TASFUL AI · リード文（固定） |
| タイトル | 例: `01. 会員登録方法` |
| 質問カード | 💬 質問 · ユーザーが聞きそうな質問文 |
| AI 回答ボックス | intro · 段落 · 手順 · 箇条書き · 注意ボックス |
| CTA | 詳細・関連アクション（データ定義） |
| 関連ページ | サイト内リンク群 |
| フィードバック | 「役に立ちましたか？」 |
| 出典注記 | データ由来の一行（任意 · AD-012 準拠） |

### 詳細ページ専用ラッパー（コンポーネント外）

| ブロック | 内容 |
| --- | --- |
| 補足 | ページフッター付近の追加注記 |
| 関連 QA | 他トピックへの導線 |
| 更新日 | コンテンツ更新日 |
| 前後 QA | シリーズ内ナビ |

## サイト内 AI の検索結果種別（3 種のみ）

| 種別 | 条件 | 表示 |
| --- | --- | --- |
| **① QA** | QA 意図のみ · 登録データ検索不要 | **QA 記事コンポーネント**（全文） |
| **② 検索カード** | 業者 · 求人 · 商品 · 店舗 · 市場等 | 既存 `ai-search-result-card` 系 UI |
| **③ QA + 検索カード** | QA 意図 + データ検索が有用 | ① の **後に** ② を続けて表示 |

**禁止:** 上記以外の ad hoc ハイブリッド · QA 用と AI 用の二重 UI · 検索カードと QA 本文の同一カード混在

---

## 禁止事項（設計）

| 禁止 | 理由 |
| --- | --- |
| AI 専用の別回答 UI | 二重管理 · 表示ズレ |
| QA ページ用と AI 用で内容を二重管理 | Single Source of Truth 違反 |
| QA ごとの独自レイアウト | 保守コスト · UX 不統一 |
| チャット内で AI が自由文を長文生成して QA 代替 | データ正本が QA マスタでなくなる |
| 検索カード UI への QA 要素の混入 | 責務分離 |

## UI レビューデモとの関係

`ai-workspace-ui-review-demos.js` の **サイト内 QA（カードなし）** セクションは、将来抽出する **QA 記事コンポーネントの UI 参照実装** とする。

本番適用時はデモ HTML 生成ロジックを **共有コンポーネント** として切り出し、Workspace 回答レンダラ · `/help/*` ページの双方から呼び出す（[TODO.md](../TODO.md) QA-D-02 / QA-D-05 / QA-D-07）。
