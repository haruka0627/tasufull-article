## 1. Owner オンボーディングフロー

```text
[1] 掲載作成 (new.html)
  → 種別選択（店舗・販売 / 業務サービス）
  → カテゴリ選択
  → 基本情報入力（店舗名・所在地・連絡先・紹介文）
  → AI 下書き生成（任意）
  → 下書き保存 (draft)

[2] 詳細編集 (edit.html)
  → 写真アップロード
  → 営業時間設定
  → 詳細紹介文（Standard+ で公開）
  → FAQ 設定（Standard+ で公開）
  → おすすめ用途（Standard+ で公開）
  → SEO 設定（タイトル・説明）

[3] プラン選択
  → Free: 基本掲載（short_description のみ公開）
  → Standard (¥980/月): 写真・営業時間・詳細・FAQ・用途 公開
  → Pro (¥2,980/月): Standard + 写真上限 20 枚

[4] 審査申請
  → 申請ボタン → status: review_requested
  → 運営が admin/reviews.html で確認
  → 承認 → status: published（公開）
  → 差戻 → status: rejected（再編集可能）

[5] 公開後
  → public/list.html に掲載
  → public/detail.html に詳細ページ
  → edit.html から内容更新 → content_update 申請 → 承認 → 反映
```

## 2. 審査基準（運営向け）

| 項目 | チェック内容 |
| --- | --- |
| 店舗名 | 実在する事業者名か |
| 連絡先 | メールアドレスが有効か |
| 紹介文 | 公序良俗に反しないか |
| 写真 | 著作権侵害がないか |
| カテゴリ | 適切なカテゴリが選択されているか |
| 所在地 | 実在する住所か |

## 6. FAQ（公開用草案）

### Q. 掲載は無料ですか？
A. Free プランは無料です。基本情報（店舗名・所在地・紹介文）を公開できます。写真や詳細情報の公開には Standard プラン（¥980/月）以上が必要です。

### Q. 審査にはどのくらい時間がかかりますか？
A. 通常、営業日 [XX] 時間以内に審査結果をお知らせします。

### Q. 掲載内容は後から変更できますか？
A. はい。edit.html からいつでも編集できます。変更内容は再審査後、公開ページに反映されます。

### Q. 複数の店舗・サービスを掲載できますか？
A. はい。1 アカウントで複数の掲載を作成できます。

### Q. 解約はできますか？
A. はい。有料プランは Stripe Billing Portal からいつでも解約できます。解約後は Free プランに戻ります。
